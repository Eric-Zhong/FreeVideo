# 11 · 安装部署与启动器架构

> FreeVideo 的“一键部署”是其易用性关键：每个平台分发包会**先 bootstrap 隔离工具链，再安装 ComfyUI + 运行时 + 模型**，最后启动 ComfyUI（Web UI 即 ComfyUI）。本篇拆解安装、启动器与自更新。

## 1. 平台启动脚本（bootstrap 工具链）

- **Linux/macOS**：`freevideo`（bash）/ `setup.sh` → 源 `scripts/bootstrap_linux.sh` → `exec $BOOTSTRAP_PYTHON -m freevideo_engine.managed`（或 `freevideo_engine.bootstrap`）。
- **Windows**：`freevideo.cmd` → `freevideo.ps1` → `windows_bootstrap.ps1` 用系统 curl 多源探测 + SHA-256 校验下载 `uv`（python-build-standalone），再 `python -m freevideo_engine.managed`。
- **工具链版本锁定**：`bootstrap_versions.json`（Python `3.12.3`、uv `0.9.0`、MinGit、SageAttention、CUDA 12.9/13.0）。macOS 的 uv 来自校验过的 PyPI wheel（`macos_bootstrap.prepare_uv`）。

## 2. 安装编排

```mermaid
flowchart TD
    A[平台启动脚本 bootstrap uv/Python] --> B[managed / bootstrap.main]
    B --> C[bootstrap.plan<br/>硬件盘点 + 模型计划 + 磁盘估算]
    C --> D[Installer + install_schedule<br/>依赖 DAG + 有界线程池]
    D --> E[构建 venv(s)<br/>environments.py]
    D --> F[克隆 VDN/Diffusers 源<br/>install.py]
    D --> G[下载/校验模型<br/>provision.py + model_files.json]
    G --> H[部署到 ComfyUI<br/>comfy_launcher_runtime.deploy]
    H --> I[启动 ComfyUI 服务<br/>浏览器打开 Web UI]
```

- **`bootstrap.py`**：`plan()` 建安装计划；`Installer`（含 `setup.lock`/`engine.lock`）设环境变量（`FREEVIDEO_*`、`UV_*`、硬链接模式）并跑 `component_tasks`。
- **并发/依赖**：`install_schedule.py` 用有界 `ThreadPoolExecutor` + 前置 DAG + 排他写者。
- **多 venv 布局**：`environments.py` 定义 `unified`/`engine`/`encoder`（各自锁定 torch + CUDA tag）；`macos_setup.py` 子类化 `Installer` 适配 MPS/int8 ConvRot。
- **模型**：`provision.py` 下载并校验 `model_files.json` 中 pin 的文件（HF `repo/revision/sha256/git_blob` + `download_sha256`）。`install_disk.py` 做磁盘预算，`install_tuning.py` 做复用/调优。

## 3. 模型分发与离线包

- **来源/镜像**：`network.py` 定义 `torch/models/vdn-models/edge-models/image-models` 家族，镜像 `official`(hf)/`hf-mirror`/`modelscope`；下载**校验 sha256/git_blob、可断点续传、镜像回退**。HF Token 仅发往 `official`/`user`。
- **用户偏好与探测**：`download_settings.py`（`auto|official|hf-mirror|modelscope`，`Probe` 测速排序，代理模式）；`download_cache.py` 用 `posix_fadvise(DONTNEED)` + `fdatasync` 释放下载页 RAM。
- **离线模型包**：`offline_packages.py` 导入预构建 ZIP（夸克/HF 镜像/ModelScope），前缀 `FreeVideo-Windows/`，变体 `common|rowwise|per_tensor|int8_convrot`；四类包（视频模型、文本编码器、视频&音频解码器、采样缓存）+ 可选参考音频包 + Windows 专用环境包。云链接在 `model_shares.json`（`pan.quark.cn`）。
- **本地复用**：`local_models.py` 扫描最多 64 个已有库，按大小匹配再校验 sha/git_blob，硬链接或拷贝，避免重复下载。

## 4. 启动器应用架构（桌面 App vs Web）

存在**两套 GUI 栈**：

1. **一键启动器（PySide6 / QtQuick QML，主端用户 App）**：`modern_launcher.py` → `create_ui()` 用 `QQmlApplicationEngine` 加载 `launcher/Main.qml`，Python `Bridge(QObject)` 暴露 `state`/`downloadList`（`QTimer` 轮询 `launcher_session.Session`）。强制 `QSGRendererInterface.Software` 渲染以免占用生成 GPU。`launcher_session.py`（~128KB）驱动安装/启动/更新/终端/离线导入；`launcher_*.py` 为其 QML 后端件。
2. **引擎桌面工具（Tkinter）**：`desktop.py` 的 `Desktop`（Setup/Generate/Test&tune/Reports 标签页），引擎自身运维 UI，独立于 ComfyUI 启动器。

**与 Web UI 的关系**：启动器**不渲染视频 UI**，而是部署并启动一个独立的 **ComfyUI 服务进程**（默认 `http://127.0.0.1:8188`）并在浏览器打开它——**ComfyUI 即 Web UI**。桥接：`comfy_launcher_runtime.Controller`（部署、启停、端口/局域网/访问链接、回收旧版本）、`comfy_launcher_api.py`（`/freevideo/launcher` 端点）、`comfy_updates.py`（网页回发更新/重启请求）。

## 5. 平台差异

- **Windows**：`windows_bootstrap.ps1` 下载 uv（多源测速 + SHA256），长路径处理（`long_paths.py`）；双 venv + CUDA/SageAttention 构建；`scripts/windows_app.py`/`build_windows.py` 出 `.exe`/App。
- **macOS**：`macos_bootstrap.require_native()` 强制 Apple Silicon；`scripts/macos_app.py`/`build_macos.py` 出 `.app`；`macos_runtime.py`/`macos_process_host.py`（psutil 进程树监管）/ `macos_shortcut.py`。
- **Linux**：`./freevideo` + `bootstrap_linux.sh`，PyInstaller **AppImage**；`linux_bundle.py` 剥离 `LD_LIBRARY_PATH`/APPIMAGE/Qt 变量；`linux_process_host.py` 用 `SUBREAPER`（prctl）收养孤儿进程。
- **便携/离线**：`portable.py` + `portable_launcher.py`（`PortableLauncher`/`PortableSession`，`portable.json`）做自包含包。

## 6. 自更新（Ed25519 可信锚点）

- `freevideo_source_bootstrap.py`：刻意放在 `freevideo_engine` **之外**的冻结可信锚点，`activate()`（由冻结启动器调用）读取 PyInstaller 包内 `source-base.json`，再应用 `overlay/active.json` 的累积**稀疏源覆盖**。
  - `manifest()/prepare()` 对每个更新跳做签名校验（schema、仓库 `FlashML-org/FreeVideo`、channel、身份哈希）。
  - `compose()/SourceFinder` 在 `sys.meta_path` 上重定向 `freevideo_engine` 包，使新源在恢复时无需网络即可遮蔽冻结包。
  - `lease()/in_use()` 用锁文件保证**运行中的版本**永不被另一启动器删除/覆盖。
- `freevideo_ed25519.py`：从零实现的 RFC 8032 Ed25519 `verify()/sign()`（子群/编码校验）。
- `freevideo_update_keys.py`：受信任公钥（`ED25519_PUBLIC_KEY`）。

> 所有冻结分发包均调用 `freevideo_source_bootstrap.activate()` 从包内重定向引擎源，从而获得“可验证、可恢复”的 OTA 自更新路径。

## 7. 设计要点

- **隔离优先**：先 bootstrap 隔离 uv/Python venv，再装一切，避免污染系统环境。
- **可恢复安装**：依赖 DAG + 排他锁 + 断点续传 + 本地复用，降低大体积模型安装失败成本。
- **启动器与引擎解耦**：启动器只负责“装 + 启 ComfyUI”，视频 UI 完全交给 ComfyUI，职责清晰。
- **安全自更新**：源覆盖 + Ed25519 签名 + 运行锁，兼顾 OTA 与回滚安全。
