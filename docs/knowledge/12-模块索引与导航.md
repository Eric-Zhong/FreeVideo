# 12 · 模块索引与导航（速查表）

> 本篇是 `freevideo_engine/` 关键模块的**按子系统分类速查表**，便于按职责定位源码。配合 `02` 的目录分布与前述各专题阅读。

## 1. 生成主链路

| 模块 | 职责 |
|---|---|
| `generate.py` | 请求入口、规划、准入、派发（父进程） |
| `worker.py` | 隔离采样 + 解码 worker |
| `runtime.py` | `Engine`：模型加载、打补丁、采样入口 |
| `two_pass.py` | 两通道（预览/精修）规划 |
| `conditioning.py` | 文本条件化契约 |
| `media_encoding.py` | 参考媒体 → VAE latent |
| `decode.py` / `decode_stream.py` / `decode_prefetch.py` | 视频 VAE 解码、流式、预读 |
| `latent_upscale.py` | 两通道 latent 上采样 |
| `encode.py` / `encode_worker.py` | 文本/视觉编码器子进程 |

## 2. 模型适配与注意力

| 模块 | 职责 |
|---|---|
| `attention.py` | `WindowAttention`，注意力后端选择 |
| `head_chunk.py` | head 分组限界（省显存分片线性） |
| `blocks.py` | 融合 H3 块、丢弃激活、分块 FF |
| `adaln.py` / `adaln_assets.py` / `adaln_reclaim.py` | 预计算 AdaLN 调制表 |

## 3. 内存与精度自适应

| 模块 | 职责 |
|---|---|
| `offload.py` | `LayerOffloader` 顺序 offload + 预取 |
| `streamed_weights.py` | `SafetensorLayers` mmap 流式权重 |
| `activation_staging.py` | `HeadReadouts` 激活暂存 |
| `gpu_budget.py` / `capacity.py` | Windows 分配器上限 / 准入 |
| `compute_budget.py` | 按富余显存放大并行/分块 |
| `fp8.py` / `fp8_ops.py` / `fp8_gemm.py` | FP8 权重/投影/GEMM |
| `int8_ops.py` / `weight_only.py` | int8 ConvRot / 仅权重量化 |
| `kernel_capabilities.py` | 执行回执式后端选择 |
| `calibration.py` / `capabilities.py` / `adaptive.py` | 配对测量 / 准入估算 / 重试 resume |
| `encoder_*.py` / `model_read_ahead.py` / `cold_pages.py` | 编码器内存策略与预读 |
